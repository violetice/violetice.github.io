一位爱好广泛的叉车师傅

你好，我是Violet_ice紫冰。欢迎来到我的小作坊。

是一名生于 98 年初的小青年。当年学习不好，没本事上大学，上了个 2+3，专业是会计电算化。考了三年的会计从业资格证，没考出来。随后就取消了这个证[1]。

后来表哥去学了 php，大概半年后我也报了培训班。如今一直在从事全栈开发。

太TM卷了，我是卷不动了，躺平了。失业三宝跑滴滴中，一个月七八千的也心满意足了。 搞网站开发工资顶天就到4500。

自从广州有案例开始严打双证司机接顺风车单[2]，那会网络上沸沸扬扬，我也就急流勇退了。毕竟跨省放空回来太难受了，怎么也得接一单顺风车。
直接注销了《网络预约出租汽车运输证》，不过放现在也过期了。一年一续的玩意。

但是《客运出租汽车驾驶员证》还在，以后说不定尝试一下正宗的巡游出租车。毕竟这不是水货《网络预约出租汽车驾驶员证》。而且有效期也是直接到我60岁，2058年。

目前帮我爸干活中，彻底躺平了。时不时的跑个顺风车，还不知道以后结婚了该怎么办呢。

结我婚了，2026年10月21日。

顺风车也好久没跑了，直接变自由人，整个11月份可以畅玩。12月回来再找工作。我要去考叉车证！

还是得有一门硬功夫，才不容易被AI给顶替了。我自己也在用，AI真的是太香了。太好用了。

名称的来源，其实与 Minecraft 有关啦。早年前碰过 alpha 版本，应该也都知道的，只能放方块和破坏，其他什么都干不了。 时间来到 2014 年，在优酷看到了岷叔，此后的三年就一直在 MC 圈子混，也模仿了这一群人的名称风格。

还因为 MC 而去自学了 java，虽然没学会~。但掌握了一门语言之后，在回来自学 java 就很简单了。

我还是一名自媒体创作者，当然主要还是游戏，还是以跑跑卡丁车为主的。
